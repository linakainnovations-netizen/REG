# St. Charles Lwanga Regiment Portal

## Parish Portal — Reviewer Preview Guide

Dear Reviewer,

Thank you for taking time to review the St. Charles Lwanga Regiment Portal. This guide explains how to open the preview site and sign in to each dashboard.

### 1. Opening the Preview

Open the following link in your browser (Chrome or Edge recommended):

**Preview link:** https://linakainnovations-netizen.github.io/REG/

If the link does not open, the site administrator may still be enabling it. Please wait a few minutes and try again.

### 2. Signing In

1. On the preview homepage, click **Sign In**.
2. Enter your assigned **username** (see the list below).
3. Enter the default password: **REGIMENT**.
4. Click **Sign Into Portal**.

The same default password, **REGIMENT**, applies to every demo account.
